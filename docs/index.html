Methode

  • Bron: open data van Infrabel (CC0): ruwe stiptheidsgegevens per trein en per meetpunt (dag D-1 en maandarchieven), officiële maandstiptheid per stopplaats en vertragingsoorzaken.
  • Stipt: aankomst met minder dan 6 minuten vertraging, zoals Infrabel het definieert. Alleen officiële stopplaatsen tellen mee; afgeschafte treinen zitten niet in de ruwe gegevens.
  • Verwerking: SQL in DuckDB, Python en GitHub Actions; de pagina wordt meerdere keren per dag opnieuw gebouwd, de gegevens lopen tot en met gisteren.
  • Code en data: github.com/BadaninaAnna/treinstiptheid-belgie · Anna Badanina
